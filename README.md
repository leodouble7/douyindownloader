# Media Security Lab

项目地址：[https://github.com/leodouble7/douyindownloader.git](https://github.com/leodouble7/douyindownloader.git)

Media Security Lab 是一个用来检查视频播放页面访问情况的桌面工具。你给它一个自己拥有或获准测试的公开视频页面，它会打开页面、记录测试过程，并把发现的问题和结果整理成报告。软件面向 Windows 和 macOS。

> **使用声明：本项目仅作为个人研究使用，禁止分发。任何因使用、复制或传播本软件产生的后果，由使用者自行承担，与本软件作者无关。**

## 软件能做什么

- **观察播放过程**：在软件内打开指定页面，查看页面是否加载了视频、音频，以及软件识别到的媒体文件。
- **检查访问限制**：对已发现的媒体进行有限度的验证，帮助你判断服务器是否真正限制了访问。每项结果都附有过程记录，方便回头核对。
- **验证完整下载**：在你明确选择该模式并再次点击开始后，尝试保存可访问的视频和音频。两者都成功时，软件会尝试合成为一个可播放文件。
- **生成本地报告**：汇总测试结论、依据和建议，可查看并保存报告。测试历史保存在本机，方便比较调整前后的结果。

软件会区分“媒体可以访问”“服务器明确拒绝”“内容受到加密保护”和“这次测试无法判断”。**测试失败不等于视频已经受到有效保护**，请以报告中的具体证据为准。

## 如何使用

1. 输入一个具体的公开视频页面地址。一次只测试一个页面。
2. 选择本机文件夹，用来保存报告和验证文件。
3. 选择测试方式：
   - **只观察**：查看页面播放时发现了什么，不做访问验证。
   - **标准安全验证**：在观察之外，检查已发现媒体的访问限制。
   - **完整下载验证**：先完成标准验证，再由你决定是否下载完整文件。
4. 确认你拥有该页面或已经取得测试授权，然后开始。播放页面中的视频，让软件有机会识别视频和音频。
5. 在工作台查看过程记录和结果。需要完整下载时，选择对应的视频、音频并点击“开始完整下载与验证”；只需要结论时，可直接生成报告。

报告和下载结果保存在你选择的本机文件夹中。历史页面可以重新查看之前的测试记录。如果页面没有正常播放，或软件未能识别媒体，请先确认页面本身可访问，再重试。

## 使用范围

本工具只适用于你自己拥有或明确获准测试的内容。它不提供批量抓取、登录绕过或受保护内容解密功能，也不承诺能下载所有视频，或证明某个视频“绝对无法下载”。
