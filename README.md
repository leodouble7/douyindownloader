# 抖音音视频下载工具

项目地址：[https://github.com/leodouble7/douyindownloader.git](https://github.com/leodouble7/douyindownloader.git)

这是一个桌面工具：粘贴一条抖音视频链接或完整分享文字，选择保存文件夹，然后开始下载。软件会尽量确认链接对应的作品，避免把页面中预加载的其他视频当成你要的内容。视频和音频分开提供时，它会尝试整理成一个可播放文件。

## 主要功能

- **按链接查找作品**：一次处理一条链接。页面中有其他推荐或预加载内容时，只显示能够确认属于目标作品的版本。
- **选择画质**：只有一个可用版本时直接继续；有多个版本时，你可以选择想保存的清晰度。能够确认归属的音频会自动配对。
- **查看下载过程**：显示总进度；需要了解更多时，可以展开视频、音频和保存阶段的详情。文件大小未知时不会显示猜测的百分比。
- **取消和重试**：下载途中可以取消。某一项失败后，可单独重试该项，已经完成的文件不会重复下载。
- **直接保存到所选文件夹**：成品放在你选择的位置，同名文件不会被覆盖；完成后可以从软件里打开文件夹。

## 使用方法

1. 在“视频链接”中粘贴抖音链接或分享文字。
2. 点击“选择文件夹”，确定保存位置。
3. 点击“开始下载”。如果出现多个画质，选择其中一个即可；其余进度会在同一页面显示。
4. 下载完成后点击“打开文件夹”查看成品。

如果后台没能确认目标作品，软件会给出原因，并在需要时提供“打开抖音网页重试”。这一步由你主动点击；页面要求登录、验证或播放时，需要你在网页中自行完成。软件不会保证每条链接都能成功，遇到页面变化、内容受保护或网络异常时会如实提示，不把失败显示成成功。
