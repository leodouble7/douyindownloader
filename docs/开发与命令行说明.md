# 开发与命令行说明

本页保留源码运行、命令行和验证细节；面向普通使用者的功能介绍见[项目首页](../README.md)。

基于当前工程的 Electron + React 桌面界面、TypeScript 下载器和 FFmpeg 适配器。支持输入抖音链接、选择本地目录、查看下载进度并自动合并音视频；也保留独立命令行入口。

## 桌面工具

需要 Node.js 22 或更新版本。首次使用安装依赖，然后启动：

```bash
npm ci
npm run build
npm start
```

当前工作树已经安装依赖，可以直接运行 `npm start`，启动前会自动构建最新代码。

1. 在「视频链接」粘贴抖音链接或完整分享文字。
2. 点击「选择文件夹」选择保存位置；下次打开时会记住该目录。
3. 点击「开始下载」。工具默认在后台静音加载抖音页面并尝试播放，页面加载后观察 30 秒，不自动弹出网页。无法自动获取视频时，可主动点击「打开抖音网页重试」，按网页实际要求完成登录、验证或播放。
4. 工具按链接中的作品 ID 确认目标视频，并排除其他作品、预加载和页面特效。只有一个可用版本时直接下载；多个版本时只需选择清晰度，默认推荐已确认版本中分辨率最高的一项。分离音视频按作品资料声明的音频文件 ID 自动配对，无需手动选声音。无法确认作品或音频归属时会提示重试，不回退下载其他资源。
5. 下载时显示总进度；展开「下载详情」可查看视频、音频大小与速度，合并与校验阶段显示正在保存。
6. 成品直接保存在所选文件夹，不创建下载子目录。文件命名为 `视频_年月日_时分秒.mp4`（音频使用「音频」前缀，扩展名按实际格式），同名时添加序号，已有文件不会被覆盖。完成后点击「打开文件夹」即可定位文件。

链接、保存位置、内容选择、下载进度和结果始终在同一个页面，不需要前进或返回。运行时主按钮变为「取消下载」，链接只读、目录暂时不能更换；取消或结束后直接修改上方输入开始下一次，已保存的文件会保留。失败或取消项可在本次队列中点击「重试此项」，不会重复下载其他完成项。重试凭证只在主进程内存保留 10 分钟；过期、启动新解析或退出后会清除，需要重新解析链接。失败时保留链接、保存目录与队列中已保存的成品；当前失败项的临时分轨会清理。下载、合并和校验在系统临时目录进行，完成后发布成品并清理临时文件。解析、合并与校验阶段显示实际处理状态；文件大小未知时不显示虚构百分比。

开发模式支持热更新：

```bash
npm run dev
```

GUI 使用内存任务记录和 Electron utility process 写入文件，避免 Node 与 Electron 的原生 SQLite 模块 ABI 冲突。原始媒体链接、请求头只保留在下载服务内存中；界面只接收经过整理的状态和候选元数据。

## 命令行快速开始

需要 Node.js 22 或更新版本。首次使用执行：

```bash
npm ci
npm run douyin -- --help
```

在当前目录运行实际测试链接：

```bash
npm run douyin -- 'https://www.douyin.com/jingxuan?modal_id=7684438409082866998' -o ./downloads
```

工具会打开隔离浏览器。播放目标作品后默认观察 30 秒，按作品 ID 筛出实际请求过的可用版本。每一项已经包含其明确关联的音频；有多个版本时输入一个序号即可。**每次捕获序号会变化，应以当次列表为准。** 工具不会按大小、出现顺序或相同域名猜测音视频归属。

只分析播放方式和媒体候选：

```bash
npm run douyin -- 'https://www.douyin.com/jingxuan?modal_id=7684438409082866998' --list --observe-seconds 20
```

## 媒体直链下载

从播放器网络请求中获得视频、音频地址时，可以直接运行：

```bash
npm run douyin -- \
  --video-url 'https://CDN/媒体视频地址?参数' \
  --audio-url 'https://CDN/媒体音频地址?参数' \
  --referer 'https://www.douyin.com/' \
  -o ./downloads
```

地址中的查询参数必须保留，并用引号包住。`blob:` 是浏览器内部媒体对象地址，不能作为 HTTP 下载地址。需要时使用 `--user-agent '原请求的 User-Agent'`。

也支持单文件和单独音频：

```bash
npm run douyin -- --video-url 'https://CDN/完整视频.mp4' -o ./downloads
npm run douyin -- --audio-url 'https://CDN/音频.m4a' -o ./downloads
```

FFprobe 会检查实际轨道：完整 MP4 直接保存；只有视频的文件会保存分轨，并以退出码 `2` 提示缺少音频。文件扩展名或 MIME 不能证明里面一定包含音频。

## 合并已有文件

```bash
npm run douyin -- \
  --video-file './video.mp4' \
  --audio-file './audio.m4a' \
  -o ./downloads
```

合并使用 FFmpeg 的 `-map 0:v:0 -map 1:a:0 -c copy`，保留源编码。输出后核对流类型、编码参数、时长和包数量。当前适配器输出可播放的分片 MP4；WebM 输入会输出 WebM。

## 输出与限制

- 桌面版：成品直接放在选定目录，不留下下载子目录或诊断报告。临时文件在任务结束后清理；旧版本已有文件不自动迁移或删除。
- 命令行：每次运行生成独立子目录，保留原始分轨、最终视频及 `result.json` 验证结果。
- 命令行后续下载、探测或合并失败时，失败报告会记录已经完整下载的分轨路径及通过探测的轨道数量。可以补齐音频后使用本地合并入口；这不等同于命令行已支持跨运行自动断点续传。
- `--max-mb 4096` 默认限制每条轨道最多 4096 MiB；下载流式写盘，不把整段视频装进内存。
- 校验连续 `Content-Range`、总长度、ETag/Last-Modified 及 SHA-256。版本变化、短响应、服务端拒绝、取消和合并失败均不会报告成功。
- 页面模式使用临时隔离会话。原始播放 URL 与请求头仅用于当前进程间通信和下载，不导入浏览器账号。
- 支持完整 MP4/WebM 及其分离音视频轨。HLS/DASH 清单能被现有工程识别，但此命令不负责按清单拼接分片。单独的 M4S 媒体片段缺少初始化信息时也不能当作完整视频。
- 网页需要登录、验证码或没有产生媒体请求时会提示失败；不处理媒体解密。
- 作品匹配支持页面的结构化 JSON / URI 编码首屏资料及已观察到的 API 响应。短链接锁定首次跳转确认的作品。页面结构变化、缺少作品 ID、未观察到声明的音频，或格式无法建立确定关系时会失败；不按大小或时长猜测。清晰度列表仅包含资料与实际请求交叉验证后的版本，并非平台所有版本。
- 如果系统 DNS 返回代理的 `198.18.0.0/15` Fake-IP，下载工具会仅将 CDN **域名**交给阿里公共 DNS 的 HTTPS 接口，获得公网 IPv4；不发送媒体路径、签名或 Cookie。每次运行固定解析结果，并继续执行原有公网地址校验。
- macOS 已进行本机验证。Windows 需先构建工程现有的本机输出与媒体进程辅助程序：`npm run build:windows-output` 和 `npm run build:windows-media-runner`；本次未做 Windows 实机验证。

## 工程结构与检查

```text
src/main/douyin/options.ts          输入校验和同次捕获的媒体选择
src/main/douyin/capture-session.ts  Electron 中捕获网络与 MSE（GUI / CLI 共用）
src/main/douyin/target-work.ts      作品 ID、声明媒体地址与音频文件 ID 精确匹配
src/main/douyin/work-observer.ts    有界读取已完成的抖音页面/JSON 响应
src/main/desktop/                  桌面任务管理、IPC、目录偏好和文件进程
src/shared/desktop.ts              主进程与界面的类型协议
src/renderer/                     中文下载界面
src/main/douyin/capture-page.ts     Node 与 Electron 进程通信和取消
src/main/douyin/download.ts         访问验证 → 下载 → ffprobe → 合并
src/main/douyin/public-dns.ts       Fake-IP 网络下的公网解析回退
src/main/douyin/cli.ts              命令行入口
scripts/douyin.cjs                 编译并启动工具
```

